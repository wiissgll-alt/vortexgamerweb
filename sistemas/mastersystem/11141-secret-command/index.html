Sega Master System

Secret Command

Descripción

Secret command was released several times under different names. In japan, it is known as ashura (阿修羅) (アシュラ). In north america it was tied with the rambo movie franchise and renamed rambo: first blood part ii (with only minor graphics and music changes occurring between releases). In europe and in later re-releases of the game, it is labeled as secret command, however the title screen reads secret commando. The north american release of the game depicts rambo holding a bizarre hybrid weapon built from the m60 machine gun seen in the first movie and the rpg seen in the second. Secret command was re-released as part of the wii's virtual console service, and has appeared in numerous compilations.
