Championship Pool

Descripción

The game is a straight-forward, virtual version of pool and includes several games: eight-ball, nine-ball, three-ball, ten-ball, fifteen-ball, straight pool (14.1 continuous), rotation, equal offense and speed pool. The player may play against the computer or up to seven other players using the same console using the "party pool" (multiplayer) option. Other gameplay modes include "tournament" (single-player, computer opponents), "freestyle" (players make up own game rules) and "challenge" (single-player, shot practice).

Il gioco è una versione virtuale semplice del biliardo e comprende diversi giochi: otto, nove, tre, dieci, quindici, dritto (14.1 continuo), rotazione, pari attacco e speed pool. Il giocatore può giocare contro il computer o fino a sette altri giocatori utilizzando la stessa console utilizzando l'opzione "party pool" (multigiocatore). Altre modalità di gioco includono "torneo" (giocatore singolo, avversari controllati dal computer), "freestyle" (i giocatori stabiliscono le proprie regole di gioco) e "sfida" (giocatore singolo, pratica di tiro).
