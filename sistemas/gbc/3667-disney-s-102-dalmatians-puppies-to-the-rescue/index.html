Descripción

Cruella de vil has captured more dalmatian puppies to make into a coat. You, as domino or oddball, must free them. Disney's 102 dalmatians: puppies to the rescue on the game boy color is a 2d, side-scrolling platform game. You must run and jump about the level, searching for a key.
