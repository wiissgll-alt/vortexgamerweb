Super Lode Runner II

Descripción

The second compilation of levels from irem's lode runner arcade series. Developed for the famicom disk system, it was never released outside of japan. Irem created four arcade versions of the original lode runner, each with a unique set of levels as well as added features like a co-operative mode for two players. For the fds home versions, irem compiled several levels from each of these arcade versions onto one disk. Super lode runner ii has fewer single-player levels than its predecessor, but contains more co-op levels to make up for it.
