Descripción

Pyramid magic (ピラミッドマジック) is a puzzle-platform game for the sega mega drive, released exclusively in japan via the sega game toshokan service. The basic aim of the game is to get to a goal, which often involves collecting keys, opening chests and moving blocks. A kicks, c jumps. Pressing c twice causes the player to attack blocks underneath the player. Pressing b while next to a stone block allows the player to pick it up, and then he/she can drop it with the same button. Pressing c + start causes the level to reset. A + start allows you to skip the level, though this can only be used three times during the course of the game.
