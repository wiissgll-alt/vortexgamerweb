Descripción

Pyramid magic (ピラミッドマジック) is a puzzle-platform game for the sega mega drive, released exclusively in japan via the sega game toshokan service. The basic aim of the game is to get to a goal, which often involves collecting keys, opening chests and moving blocks. A kicks, c jumps. Pressing c twice causes the player to attack blocks underneath the player. Pressing b while next to a stone block allows the player to pick it up, and then he/she can drop it with the same button. Pressing c + start causes the level to reset. A + start allows you to skip the level, though this can only be used three times during the course of the game.

Pyramid Magic (ピラミッドマジック) è un gioco puzzle-platform per Sega Mega Drive, pubblicato esclusivamente in Giappone tramite il servizio Sega Toshokan. Lo scopo fondamentale del gioco è raggiungere un obiettivo, che spesso comporta la raccolta di chiavi, l'apertura di forzieri e lo spostamento di blocchi. A calcia, c salta. Premendo c due volte il giocatore attacca i blocchi sotto di lui. Premendo b mentre si è accanto a un blocco di pietra si consente al giocatore di raccoglierlo e poi di rilasciarlo con lo stesso pulsante. Premendo c + start si ripristina il livello. Un + inizio ti consente di saltare il livello, anche se può essere utilizzato solo tre volte nel corso del gioco.
