Descripción

Doroppu is a brand new indie homebrew game for the sega genesis / megadrive. It is a tile matching game with influences taken from puyo puyo and puzzle bobble to create a unique new experience. Doroppu can be played by 1 player, or 2 players in split screen vs mode. Created using basiegaxorz, doroppu is repixel8's first of a line of new games for sega's 16 bit console. Doroppu is released as a rom download, with a limited physical cartridge release following.
