Hot Memory (V1.2, Germany, 12/28/94)

Descripción

Hot memory is a stripped down clone of the 1994 strata game "pairs - featuring the giffy girls". Unlike "pairs", hot memory lacks a stage select, launching straight into the game, with each stage featuring a different girl in the background.
