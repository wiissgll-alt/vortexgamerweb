Descripción

5000 savings bond. Machines can also be set (via dip switches) to suppress this screen, in which case players would get a screen saying '5000 points x coins = xxx' after doing the secret room. The contest ended in 1986. Note : the game contains exactly 205 sounds! (including digitized voices, effects and musics), less than the first gauntlet.
