Descripción

Volleyball is an action game which can be played by one or two players. The game follows traditional volleyball rules; the first team to score 15 points wins! you control both players on the team, which have the ability to serve, set, spike, and block. There are several game variations included; two game difficulties and two player speeds. In the easier version of the game, the ball will automatically be sent back over the net when hit. In the advanced version, the game also allows you to set the ball between teammates. In either version of the game with either one or two players, the speed at which the players run can be set to either fast or slow for an extra challenge or to handicap one team.

Le volley-ball est un jeu d'action qui peut être joué par un ou deux joueurs. Le jeu suit les règles traditionnelles du volleyball ; la première équipe à marquer 15 points gagne ! vous contrôlez les deux joueurs de l'équipe, qui ont la capacité de servir, de définir, de frapper et de bloquer. Il existe plusieurs variantes de jeu incluses ; deux difficultés de jeu et deux vitesses de joueur. Dans la version la plus simple du jeu, le ballon sera automatiquement renvoyé par-dessus le filet lorsqu'il sera touché. Dans la version avancée, le jeu permet également de passer le ballon entre coéquipiers. Dans les deux versions du jeu avec un ou deux joueurs, la vitesse à laquelle les joueurs courent peut être réglée sur rapide ou lente pour un défi supplémentaire ou pour handicaper une équipe.

La pallavolo è un gioco d'azione a cui possono partecipare uno o due giocatori. Il gioco segue le regole tradizionali della pallavolo; vince la prima squadra che segna 15 punti! controlli entrambi i giocatori della squadra, che hanno la capacità di servire, impostare, schiacciare e bloccare. Sono incluse diverse varianti di gioco; due difficoltà di gioco e due velocità del giocatore. Nella versione più semplice del gioco, la palla verrà automaticamente rimandata in rete quando viene colpita. Nella versione avanzata, il gioco permette anche di posizionare la palla tra i compagni di squadra. In entrambe le versioni del gioco con uno o due giocatori, la velocità alla quale i giocatori corrono può essere impostata su veloce o lenta per una sfida extra o per handicappare una squadra.
