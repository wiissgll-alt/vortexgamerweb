SNEAK 'N PEEK

Descripción

Sneak 'n peek is a computerized version of the game hide and seek. The game is played by two players (or one player against the computer); one player will close his eyes while the other player hides somewhere. After the second player is hidden, the first player needs to locate him in the shortest time possible. After the second player has been located, the roles will then be reversed. The game takes place in an old house with three rooms available as well as the front yard to hide in; each of these four locations contains five different places to hide. The game can be played with fixed or variable hiding locations; in the fixed game, the hiding locations will always be found in the same place, and the variable game will move the hiding places around each time a room is entered. Two difficulty levels are available; in the tougher setting, the entrance to the hiding places is narrower making it tougher to find.

Sneak 'n peek est une version informatisée du jeu de cache-cache. Le jeu se joue à deux joueurs (ou à un joueur contre l'ordinateur) ; un joueur fermera les yeux tandis que l'autre joueur se cachera quelque part. Une fois le deuxième joueur caché, le premier joueur doit le localiser dans les plus brefs délais. Une fois le deuxième joueur localisé, les rôles seront alors inversés. Le jeu se déroule dans une vieille maison avec trois pièces disponibles ainsi que la cour avant pour se cacher ; chacun de ces quatre emplacements contient cinq endroits différents où se cacher. Le jeu peut être joué avec des cachettes fixes ou variables ; dans le jeu fixe, les cachettes seront toujours trouvées au même endroit, et le jeu variable déplacera les cachettes à chaque entrée dans une pièce. Deux niveaux de difficulté sont disponibles ; dans le contexte le plus difficile, l’entrée des cachettes est plus étroite, ce qui rend la recherche plus difficile.

Sneak 'n peek è una versione computerizzata del gioco nascondino. Il gioco è giocato da due giocatori (o un giocatore contro il computer); un giocatore chiuderà gli occhi mentre l'altro si nasconderà da qualche parte. Dopo che il secondo giocatore è stato nascosto, il primo giocatore deve localizzarlo nel più breve tempo possibile. Dopo che il secondo giocatore è stato localizzato, i ruoli verranno invertiti. Il gioco si svolge in una vecchia casa con tre stanze a disposizione oltre al cortile dove nascondersi; ciascuna di queste quattro posizioni contiene cinque posti diversi in cui nascondersi. Il gioco può essere giocato con nascondigli fissi o variabili; nel gioco fisso i nascondigli si troveranno sempre nello stesso posto, mentre nel gioco variabile i nascondigli si sposteranno ogni volta che si entra in una stanza. Sono disponibili due livelli di difficoltà; nell'ambiente più difficile, l'ingresso ai nascondigli è più stretto, rendendolo più difficile da trovare.
