Descripción

Super star soldier takes place in the far future, where you are the last hope for planet earth, which is being attacked by an alien race. The game features top-down view with vertical scrolling levels, similar to it's prequel star soldier. The game features the following game play modes: normal play, score play, 2 minutes play and 5 minutes play. Each level has it's own tough boss at the end.

Consejos

  • En la pantalla de título, mantén SELECT y pulsa ARRIBA, ABAJO, ARRIBA, ABAJO, IZQUIERDA, DERECHA, IZQUIERDA, DERECHA, I, II para desbloquear el modo difícil.
  • At the title screen, hold SELECT and press UP, DOWN, UP, DOWN, LEFT, RIGHT, LEFT, RIGHT, I, II to unlock Hard Mode.
  • À l'écran titre, maintenez SELECT et appuyez sur HAUT, BAS, HAUT, BAS, GAUCHE, DROITE, GAUCHE, DROITE, I, II pour déverrouiller le mode difficile.
  • Nella schermata del titolo, tieni premuto SELECT e premi SU, GIÙ, SU, GIÙ, SINISTRA, DESTRA, SINISTRA, DESTRA, I, II per sbloccare la modalità Difficile.
